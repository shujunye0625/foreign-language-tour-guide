## 综知补入要点（摘要）

- **丹霞 Q28**：岭南四大名山（丹霞、罗浮、西樵、鼎湖）  
- **开平 / 陈家祠 Q10**：世遗碉楼 vs 礼制陈家祠在岭南建筑谱系中的位置  
- **南越 Q12**：玉印 9 枚；身上 3 枚「赵昧」「泰子」「帝印」（与文帝**金**印区分）  
- **南越 Q3/Q4/Q16**：南海郡 / 赵佗开国 / 五王 93 年 / 前 111 归汉  
- **陈家祠 Q14**：爵禄封侯（雀鹿蜂猴）  
- **陈家祠 Q19/Q22**：六类工艺 + 牡丹/并蒂莲/狮  
- **陈家祠 Q26**：1893 陈伯陶探花与石鼓  
- **不写入**：综知 Q24 南华寺（非丹霞）

## 怎么用

1. 打开 App 首页「景点讲解」进入对应景点。  
2. 默认「逐句突破」：当前句循环范读，点下一句才前进；听/跟自动计数。  
3. 熟练后切换「整篇连播」验收串讲。  
4. 点英文词可查义；跟读仅录音回听，不做 AI 纠音。

已接入影子跟读 App：`data/scenic_guides/` + `audio/scenic_guides/`。
